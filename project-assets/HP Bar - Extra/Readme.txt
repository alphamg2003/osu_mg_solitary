There are two types of Progress Display: Top-Right Pie and Top-Right Bar
You can change it in Settings -> Gameplay -> General -> Progress Display
When changing, be sure to use correct file of scorebar-bg to match the current progress display!!

How to replace:
- Get yourself any type of Progress Display you want, with corresponding scorebar-bg-y and scorebar-bg@2x-y
- Delete current scorebar-bg and scorebar-bg@2x in the main folder
- Paste the scorebar-bg-y and scorebar-bg@2x-y inside, then rename it by removing the "-y" behind
Example: scorebar-bg-pie.png -> scorebar-bg.png
